<h3 align="center"><b>Pi-Plane Space</b></h3>
<p align="center"><b>The read-only pages of projects shared on the web</b></p>

Space serves the pages behind a project's web link (`/spaces/issues/<anchor>`): work items in the layouts the project chose, with optional comments, reactions and votes. Viewers do not need an account to read; writing needs a sign-in. See [web sharing](../../docs/web-sharing.md).
